# Local Obsidian setup

From the code checkout run `python -m engine.vault D:/AURA-Local-Vault` (choose a location outside all Git repositories). Open the folder as a vault in Obsidian, then open 00_Dashboard/Home.md. Existing notes are preserved. Never sync private data to the public repository. No network calls. Actual device setup, mobile sync and concurrent filesystem/junction hardening remain unverified.
