# Security policy

Public repository: code and synthetic fixtures only. Never commit personal notes, exam banks, trading records, credentials or real evidence. Keep actual vault outside Git checkout. Source repositories must use read-only credentials; no source writes or scheduling changes. No automatic approval of inferred knowledge. CI uses read-only permissions, no secrets, no scheduled trigger. Review every diff before publication. Ignore rules are defense in depth, not a confidentiality guarantee. Report leaks privately and rotate exposed credentials.
